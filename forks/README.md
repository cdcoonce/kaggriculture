# forks/

Local, machine-committed modifications of third-party public-leader agents
(see `eval/opponents/public-leaders/`), each under its own `<base>-fN/`
directory with a top-of-file Apache-2.0 §4(b) notice naming the base, its
license, and the changes made. Loaded via the `file:<repo-relative-path>`
harness agent spec (`harness.episodes.resolve_agent` ->
`harness.public_leaders.resolve_file_agent`) -- unlike `public:`, there is no
`panel.json` entry and no SHA-256 provenance check.
