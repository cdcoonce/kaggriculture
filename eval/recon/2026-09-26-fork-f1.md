# F1 fork gate: sokolovsky-v12-f1 vs. the pinned base and the panel

Date: 2026-09-26

## Background

`eval/opponents/public-leaders/sokolovsky-v12/main.py` (Andrey Naymushin,
@andrewsokolovsky, Apache-2.0, sha256 `df4e899a...`) was uploaded verbatim as
our ladder floor. Locally it beats `public:kaito-v4` and `public:rayk-v11`
200-0 each; in a mirror (self-play) it goes 35-35-30 over 100 games, i.e. it
has no structural edge over an exact copy of itself.

Engine fact (`docs/recon/engine-mechanics.md` ~190-207): market orders resolve
by queue-slot index across both players; each slot fully drains before the
next index; within the same index, player 0 commits before player 1. A SELL
at index 0 therefore executes before an opponent's same-item SELL at a later
index is priced.

Code finding: sokolovsky-v12's basic H4 premium front-run (`_front_run`,
formerly ending at line 315 of the base file) **appends** its pre-sale to the
end of the market order list:

```python
orders.append(["SELL", item, quantity])
action["market"] = orders[:10]
```

while its H5 meta-counter (`_h5_meta_counter`, ~218-267, only active after
confirming the opponent is itself running H4) **inserts at index 0**:

```python
action["market"] = [["SELL", item, quantity], *orders][:10]
```

Against a same-lineage opponent (the mirror case, or any fork of this same
agent), the appended H4 sell prices *after* the opponent's earlier-index
orders for the same item on the same step -- an ordering asymmetry, not a
strategy difference.

## Harness change

Added a `file:<repo-relative-path>` agent spec to `harness.episodes.resolve_agent`,
resolving through a new `harness.public_leaders.resolve_file_agent`: same
`kaggle_environments.agent.get_last_callable` + fresh-namespace-per-resolution
loading as `public:`, with no SHA-256 provenance check (there is no panel
entry for an arbitrary path). Covered by four new unit tests in
`packages/harness/tests/test_public_leaders.py::TestFileSpec`.

`forks/` was added to `pyproject.toml`'s ruff `extend-exclude` alongside
`eval/opponents/public-leaders`, since it holds third-party-derived code kept
otherwise verbatim.
